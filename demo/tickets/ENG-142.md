# ENG-142: Export report as PDF

Type: Story
Status: To do

Any report can be downloaded as a PDF: company header, page numbers, and the same filters as on screen.

## Acceptance

- `GET /reports/:id/pdf` returns `application/pdf` and respects the same query filters as the HTML view.
- The PDF has the company name as a header and "Page x of y" in the footer.
- The reports page has an Export button that downloads the PDF for the current report and filters, and shows progress while the file is prepared.
- No new dependencies. Write the PDF by hand (a plain text PDF is enough).
- `npm test` stays green and covers the new code.
